# 2026-07-09

## 数据来源 API 迁移: ttt.monsnode.com → pektino.com

- 将 MediaRepository 的 BASE_URL 从 `https://ttt.monsnode.com/` 改为 `https://pektino.com/zh-CN`
- 移除 Jsoup HTML 解析，改为 Next.js RSC 负载解析
- 添加排行榜周期支持: 日榜(无后缀) / 周榜(weekly) / 月榜(monthly) / 总榜(all)
- RSC 负载通过 `Accept: text/x-component` + `RSC: 1` 请求头获取
- 从响应中提取 `initialItems` JSON 数组，映射字段:
  - url_cd → id, url → mp4链接, thumbnail → 封面, time → duration
  - pv/favorite(字符串) → Long, tweet_url → tweetUrl, tweet_account → tweetAccount
- WaterfallViewModel 新增 currentRange 状态和 changeRange() 方法
- WaterfallScreen 新增 RankingTabs 组件(日榜/周榜/月榜/总榜选项卡)
- Models.kt 新增 tweetUrl, tweetAccount 字段
- 移除 jsoup 依赖和 proguard keep 规则

## 封面预下载代理方案

- 问题: AsyncImage 通过 Coil 加载封面时，Coil 的 proxySelector 可能不生效
- 方案: 在 WaterfallViewModel 新增 preloadThumbnails()
  - 在 loadData() 中 fetchMedia 完成后调用
  - 通过 buildProxyClient() (视频文件大小检测同款 OkHttpClient，已配置代理) 下载封面
  - 保存到 cacheDir/thumbnails/{id}.jpg
  - 主线程更新 items 的 thumbnail 为 file:// URI
  - 已缓存的图片跳过下载，直接更新路径
  - 下载失败保留原远程 URL 作为 fallback
  - preloadJob 在 range 切换或刷新时自动取消重建

## 设置页"检查更新"功能

- SettingsSheet 新增"检查更新"行按钮
- 点击触发 WaterfallViewModel.checkUpdate()
  - 通过 proxy OkHttpClient 请求 GitHub API: `GET /repos/fhyxz001/twAndroid/releases/latest`
  - 解析 JSON 获取 tag_name 和 assets 中第一个 .apk 的 browser_download_url
  - 弹出 AlertDialog 显示版本号，提供"下载"按钮
- 点击"下载"触发 downloadUpdate()
  - 通过 proxy client 下载 APK
  - 通过 MediaStore.Downloads 保存到系统 Download 目录
  - 显示进度条百分比
  - 完成后弹出系统通知
- 状态管理: checkingUpdate / updateError / updateDownloading / updateProgress / showUpdateDialog
- GitHub API 反序列化用 @Serializable 数据类 GitHubRelease / GitHubAsset
