# 2026-07-09

## 数据来源 API 迁移: ttt.monsnode.com → pektino.com

- 将 MediaRepository 的 BASE_URL 从 `https://ttt.monsnode.com/` 改为 `https://pektino.com/zh-CN`
- 移除 Jsoup HTML 解析，改为 Next.js RSC 负载解析
- 添加排行榜周期支持: 日榜(无后缀) / 周榜(weekly) / 月榜(monthly) / 总榜(all)
- RSC 负载通过 `Accept: text/x-component` + `RSC: 1` 请求头获取
- 从响应中提取 `initialItems` JSON 数组，映射字段:
  - url_cd → id, url → mp4链接, thumbnail → 封面, time → duration
  - pv/favorite(字符串) → Long, tweet_url → tweetUrl, tweet_account → tweetAccount
- WaterfallViewModel 新增 currentRange 状态和 changeRange() 方法
- WaterfallScreen 新增 RankingTabs 组件(日榜/周榜/月榜/总榜选项卡)
- Models.kt 新增 tweetUrl, tweetAccount 字段
- 移除 jsoup 依赖和 proguard keep 规则
